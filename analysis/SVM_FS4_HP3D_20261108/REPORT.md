# FS4: 고정7특징 SVM에 HP3D 한 개 추가

실험 ID: `EXPLR-SVM-FS4-HP3D-20261108`. 사용자 지정의 단일 특징 추가 가설이다. 두 사람 반복 탐색자료의 현재120개를 사용하며 독립 검증·공식 선정 결과가 아니다.

## 사전 고정 특징과 가설

FS3=F1,F3,F4,F5,F6,F7,F8. FS4=FS3+HP3D의8차원이다. V0/T0 SVM-RBF의 C=1,gamma=1/9,class_weight=None 및 나머지 생성기 설정·seed0은 그대로다. 이전 T1 가중치나T2 gamma 변경을 이어받지 않았다. 알고리즘 변경이 아닌 특징 분기 비교다.

기존7열에서 전방 위치·투영비가 정상에 가깝던P1 오류가 보조3D 머리 pitch에서는 학습P1 중앙값 쪽에 더 가까웠다는 사후 관찰을 근거로, 명시적인 머리 회전각을 추가하면 P1→P0가 줄어드는지 검토한다. 이전 관찰은 성공 보장이나 독립 검증 근거가 아니다.

```text
E = midpoint(LeftEar, RightEar); N = Nose; C = Chin  # aligned D455 XYZ, metres
u = (N_y-E_y, N_z-E_z) / norm((N_y-E_y, N_z-E_z))
v = (C_y-E_y, C_z-E_z) / norm((C_y-E_y, C_z-E_z))
HP3D_t = degrees(atan2(-(u_y+v_y), -(u_z+v_z)))
HP3D = median(valid HP3D_t in original H9 common support)
```

기존 posture_geometry._exploratory_head_pitch_deg와 같은 정의이며 새 기하 수식의 발명은 아니다. MediaPipe Pose귀7/8·코0, Face턱152와 D455 metric depth를 사용한다. +Y는아래,+Z는카메라에서멀어짐, HP3D 양수는위로회전이다. 전방평행이동은상쇄되지만카메라pitch에불변이거나임상목각도인것은아니다.

## 입력·지원 프레임 검증

기존113개+P01 P5 보완7개=120개 identity/라벨을 그대로 유지했다. 원래127개 관측 중 기술적 부적격7개는 기존처럼 제외하고 실패원본은 보존했다. 기존24구간·중단실행은 합치지 않았다.

기존7열은원래H9 공동지원 집계값과 bit-for-bit 같고 재집계하지 않았다. HP3D만그지원안에서필요XYZ가유효한프레임을사용한다. 기존 helper의finite XYZ/양의Z, ray norm>1e-6,합벡터norm>1e-6 조건을재사용했다. 결측채움·새센서임계값·후보선택은없다.

120개모두HP3D 유효≥30 및 원래입력대비coverage≥50%를통과했다. 최소유효95프레임, 최소coverage63.33%, 총H9공동17945프레임 중 HP3D지원17935프레임이다. 기존CSV에저장된값을XYZ/원래helper로재검산했고 최대차이는0deg였다(사전허용오차1e-9deg). 구간중앙값과유효수는이전보조값진단과정확히같았다.

## 평가·채택 기준

같은참가자LOSO2fold 각train60/test60,각클래스학습10개/전체평가20개다. P01두날짜는같은fold에둔다. 새8열StandardScaler는train에서만fit하고첫7열통계는기존T0와같음을확인했다. T0의두모델을복원해기존OOF를재현하고FS4만2회fit했다. 후보fit 전에PLAN.json에 수식·지원규칙·120개identity·입력hash·전체params·채택기준·추가탐색없음을기록했다.

모든조건을동시에충족해야한다: P1 Recall≥80%,P0 Recall≥95%,P2~P5 각각Recall100%, Accuracy≥95.00%,Macro-F1≥T0의반올림전값. 미달이면FS3 T0를유지한다. 판정은 반올림 전 값과 수치 허용오차1e-12를 사용한다.

## 검증·보존·한계

동일120개·원래7열·H9frame identity·HP3D원식/지원/중앙값·train-only scaler·고정SVMparams/실제gamma/가중치·수렴·OOF1회·모델복원·지표/CSV/MD·사전계획/원본hash를확인했다. 기존 raw RGB/Depth 영상을 열지 않고 저장된 CSV만 사용했다.

새코드는compare_svm_fs4_hp3d.py,요약은이보고서다. 구간별HP3D/지원프레임/8열행렬/OOF/점수/모델/스케일러/계획은local_private/에만보관한다. 기존capture/geometry/공식schema/실시간모델은수정하지않았다. FS4 실행비용은이번에측정하지않았으며T0 비용을FS4 비용으로사용하지않았다.

오류를보고정한후속가설이고동일120개를반복탐색했으므로독립검증/유의성/일반화근거가아니다. HP3D는앞으로목이동이아닌턱숙임·카메라각·이파일럿수행방식을학습할위험이있다. 다른새특징/수식/집계/가중치/C/gamma를탐색하지않았다. 공식8조합/B6/IRB HOLD/Patch8보류를유지했고 새촬영·전체회귀·Commit/Push는없다.

실행: `python -X utf8 -B compare_svm_fs4_hp3d.py`; 저장검증은 `--verify`(학습없음).

## 결과 판단

FS4(기존7특징+HP3D)는115/120 정답,Accuracy95.83%,Macro-F1 95.77%였다.
FS3 T0의114/120,95.00%,94.88%보다전체지표는올랐고P0/P2~P5 Recall은모두100%를유지했다.
P1 Recall은14/20=70%에서15/20=75%로올랐다. 기존P1→P0 오류2개를교정했지만
기존에맞힌다른P1 구간1개를새로P0로틀려순이득은1개다. 남은오류5개는모두P1→P0다.

P1 Recall80%이상조건만충족하지못했으므로 **SVM-FS4-V0-T0는미채택하고
