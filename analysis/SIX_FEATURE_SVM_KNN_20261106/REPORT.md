# 동일6특징 SVM-RBF·Linear SVM·KNN 추가 비교

실험 ID: `EXPLR-SIX-FEATURE-SVM-KNN-20261106`. 반복 사용한 2인·24구간의 6-class 탐색 비교다. 독립 검증·통계적 유의성·새 참가자 일반화 결과가 아니다.

## 고정 조건

입력 **F1,F3,F4,F6,F7,F8**, 원래 H9 지원 프레임·집계·24구간·라벨·순서·첫 P0 포함을 유지했다. 2인 LOSO 각 학습12/시험12, 참가자×자세당 2구간, 자세별 전체 support=4다. 새 특징·추가 조합·보정·채움·재집계·튜닝·촬영·원본 영상 열람은 없다.

기존 compare_fixed.py의 make_model 함수 AST를 직접 재사용했다. SVM-RBF: C=1, gamma=1/9, tol=1e-3, probability=False. Linear SVM: C=1, L2/squared_hinge, dual=False, OVR, tol=1e-4, max_iter=10000. KNN: k=3, uniform, brute, Minkowski p=2. 나머지 설정도 원래 생성기와 같다. 특징이 6개여도 gamma를 1/6 또는 scale로 바꾸지 않았다.

세 모델은 각 학습 fold에서만 StandardScaler fit 후 시험에는 transform만 적용했다. 학습 mean/scale은 이전 동일6 LR 통계와 일치했다. seeds=(0,1,2,3,4), 신규 학습은 3모델×5 seeds×2fold=30회다. LR/RF는 검증된 저장 결과만 재사용했다.

환경: NumPy 2.5.3, scikit-learn 1.9.1, native thread 1. 수렴 경고는 오류로 처리한다. 기존 설정에 대한 API 폐기 예고는 설정을 바꾸지 않고 기록했다.

## 검증·보존

입력 hash/identity/라벨·기존 결과 정합성·fold 분리·train-only scaler·생성기 설정·수렴·표본당 OOF 1회·입력 불변·저장 예측/지표/CSV/보고 표 일치를 확인했다. 전체 회귀 테스트는 하지 않았다.

API 등 비수렴 경고 기록: 10건. 상세 메시지와 건수는 로컬 JSON에 보존한다.

공개 요약은 이 보고서, 실행 코드는 compare_six_feature_svm_knn.py다. 참가자별 identity/예측·fold scaler·설정·입력 hash·seed별 혼동행렬은 local_private/results.json, 전체 OOF는 local_private/predictions.csv에만 보관한다. 기존 파일과 모델은 덮어쓰지 않았다.

공식8조합·B6·IRB HOLD·Patch8 실행 보류·실시간 모델은 유지한다. 실행속도/메모리/CPU는 측정하지 않았다. 이 결과만으로 최종 모델을 자동 선정하지 않는다.

실행: `python -X utf8 -B compare_six_feature_svm_knn.py`. 저장 검증만: 같은 명령에 `--verify` (모델 학습 없음).

## 해석

**SVM-RBF와 KNN은 다섯 seed 모두 LR과 24개 구간 예측까지 정확히 같았다.** RF M0/M1도 앞선 동일6특징 비교에서 같은 예측이었다. 따라서 이번 추가 알고리즘 비교에서 기존 두 오류(P0→P1, P1→P0 각 한 건)를 더 교정하지 못했다. Linear SVM은 모든 seed에서 LR이 맞힌 정상 구간 하나를 P1로 오분류해 P0 Recall이 75%→50%로 낮아졌다.

기존9특징 대비 세 모델의 지표가 개선됐지만 F2/F5/F9 제거의 개별 효과를 분리한 결과는 아니다. 이번 고정 조건에서 LR보다 나은 예측 결과는 관찰되지 않았다. 다른 설정이나 새 참가자에서도 모든 알고리즘이 같은 성능이라는 의미는 아니다. 실행속도·모델 크기를 측정하지 않았으므로 자원 효율 우열도 주장하지 않는다.

위 경고 10건은 **전부 기존 SVC의 probability 파라미터에 대한 FutureWarning**이며 수렴 실패 경고는 0건이다. 최초 시도에서 이 API 폐기 예고를 오류로 처리해 학습 전에 중단했으므로, 모델 설정을 유지한 채 해당 예고를 기록하도록 경고 처리만 조정한 후 완료했다. 평가 수치에 따라 설정을 변경하거나 실행을 고르지 않았다.
