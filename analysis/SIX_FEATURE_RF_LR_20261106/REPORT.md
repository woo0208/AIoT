# 6특징 RF M0·M1·M2와 LR 비교

실험 ID: `EXPLR-SIX-FEATURE-RF-LR-20261106`. 기존 2명·24구간·6-class 탐색 자료의 재사용이다. 일반화·유의성·독립 검증·공식 모델 선정 결과가 아니다.

입력은 **F1,F3,F4,F6,F7,F8**이다. 원래 H9 공통 support/집계/24구간/라벨/순서를 보존하고 열만 선택했다. 참가자당 12구간, 자세별 전체 4구간이며 첫 P0도 유지한다. 촬영·원본 영상 열람·보정·채움·튜닝·추가 조합은 없다.

## 평가 조건

기존 `rf_experiment.fit_models`를 그대로 호출했다. 6-class, 500 trees, max_features=2, seeds=(0,1,2,3,4), M2 λ=0.5, 각 fold 학습12/시험12의 동일 참가자 LOSO다. RF는 과거와 같이 추가 표준화 없이 원래 특징값을 사용한다.

M0의 학습 fold MDI 순위로만 기존 p=6 rank weights (0.30,0.20,0.15,0.15,0.15,0.05)를 배정한다. 동점은 현재 열 순서다. M1은 입력에 w를 곱한 뒤 일반 RF, M2는 분할 점수에 `(1−λ)+λ·w/mean(w)`를 곱한다. 시험 자료로 순위·가중치를 정하지 않는다.

새 RF는 5 seeds×2 folds×3모델=30 forest fits다. LR 6특징 결과는 이전 고정 LR·train-only scaler 결과를 재사용하고 재학습하지 않았다. 과거 H9 RF도 저장 예측을 재사용했다. RF 핵심 Tree/Forest/rank_weights/fit_models AST는 과거 소스 snapshot과 같음을 확인했다.

RF 지표는 각 seed의 24 OOF로 계산한 뒤 5개를 평균했다. Macro-F1은 평균 혼동행렬에서 계산하지 않는다. LR은 결정적 seed 0 한 결과이며 5번 독립 실행한 것으로 세지 않는다. seed 반복도 새 참가자가 아니다.

## 검증·보존

M0/M1 전체 seed·OOF 예측 동일: True. M1의 양수 입력 배율은 CART의 특징 내 순서를 보존하므로 같은 예측이 가능하다. M2는 다른 분할 점수를 쓰므로 별도로 해석한다.

24구간 identity/라벨/행렬·기존 LR·역사적 H9·모델 설정·train-only MDI/weights·fold 분리·OOF 1회·입력 불변·지표/CSV/보고 표 일치를 확인했다. 기존 RF 가중치/RNG 합성 구조 테스트 14개 PASS이며 실제 파일럿 결과와 구분한다. 전체 회귀 테스트는 하지 않았다.

참가자별 예측·가중치/MDI·fold·입력 hash는 local_private/results.json, 전체 OOF는 local_private/predictions.csv에만 보관한다. 공개 요약은 이 보고서이며 실행 코드는 compare_six_feature_rf.py다. 기존 결과·실시간 모델·공식8조합·B6·IRB HOLD·Patch8 실행 보류는 유지한다.

실행: `python -X utf8 -B compare_six_feature_rf.py`. 저장 검증만: 같은 명령에 `--verify` (학습 없음).

## 해석과 확인된 기존 요약 오류

6특징 M0·M1은 다섯 seed 모두 LR과 24개 구간의 예측까지 정확히 같았다. 남은 오류는 같은 P0→P1 한 건과 P1→P0 한 건이다. 따라서 모델을 LR에서 M0/M1로 바꾸는 것만으로 현재 오류를 더 교정하지 못했다. M2는 seed 1·2에서 LR보다 각각 1건·2건의 추가 오류가 있었고, 나머지 seed에서는 LR과 같았다. M2의 가중 분할이 이 자료에서 이득을 준다는 근거는 없다.

기존9특징보다 현재6특징 RF 지표는 개선됐으나 F2/F5/F9의 개별 제거 효과, 새 참가자 일반화, 모델 간 실행속도·CPU·메모리 우열은 측정하지 않았다. 이번 결과로 공식 모델/실시간 모델을 자동 교체하지 않는다.

이전 `analysis/FEATURE_REVIEW_20261106/FEATURE_IMPROVEMENT_REVIEW.md`의 RF M0 H9 P0 Recall 요약은 50%로 기재돼 있으나 원래 H9 혼동행렬 5 seeds 평균은 **45%**다. 원본 pilot JSON과 후속 ablation JSON에서 모두 45%임을 확인했다. 그 과거 요약표의 표기 오류는 이번 범위에서 수정하지 않고 기록하며, 위 비교는 원본 예측에서 재계산한 값을 사용했다. 기존 LR 수치와 이번6특징 결과에는 영향이 없다.
