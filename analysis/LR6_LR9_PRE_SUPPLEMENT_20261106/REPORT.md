# 신규 탐색자료: 6특징·기존9특징 LR 비교와 정확도 하락 재진단

실험 ID: `EXPLR-LR6-LR9-PRE-SUPPLEMENT-20261106`. 직전 모델은7특징이 아닌 **6특징(F1,F3,F4,F6,F7,F8)**이었다. 이번9특징은F1~F9 전체다. 기존B0는별도로F1~F8의8특징 모델이며9특징과 혼동하지 않는다.

LR C=1, L2(l1_ratio=0), lbfgs, tol=1e-4, max_iter=10000, intercept=True, class_weight=None, random_state=0. 기존fixed_lr 생성기를 재사용하고 StandardScaler는 각 train fold에서만 fit했다. 평가 단위는 구간이며113개 OOF pooled6-class 지표다. 각 모델에서 특징 수만 다르다. 추가 조합·다른 알고리즘·튜닝은 하지 않았다.

## 해석 범위·보존·검증

- 반복 구간 수는 늘었지만 독립 참가자는여전히2명이다. 기존24구간은 반복 탐색·특징 선택에 사용한 작은 자료다. 그때의91.67%를 새 자료에서 보장할 수 없다. 정확도는 예측 정답 비율이며 개별 예측확률이나 확률 보정 성능과 다른 지표다.
- P5 얼굴 결측7구간은 모두 한 사람에게 발생해 학습 P5가3개인 fold가 있다. P5 오류와 동시에 관찰되지만 결측 수·수행 방식·개인차 중 무엇이 원인인지는 이 비교로 분리되지 않는다. 7구간 보완만으로 P0/P1까지 개선된다고 보장하지 않는다.
- 카메라 설치·체형·의복/흉부ROI·자세 수행·세션 차이가 특징 분포를 바꿀 수 있다. 설치 metadata 미기록이고 원본 영상을 보지 않았으므로 특정 물리적 원인으로 확정하지 않는다. 시험 참가자의 분포를 scaler fit이나 모델 학습에 사용하지 않았다.
- 동일113 identity/6열 일치/9열 순서·원본/이전 결과 hash, train-only scaler/참가자 분리/OOF1회, LR 파라미터/수렴, 모델 복원, 점수·확률·계수 기여 합, 지표/CSV/MD 일치를 검증했다. 전체 회귀·원본영상 열람·촬영·새 특징 구현은 하지 않았다.
- 실행 코드 compare_new_pilot_lr9.py와 이 요약 외에 참가자 특징·범위·예측·판정점수·계수 기여·fold별 모델·사전계획은 local_private/에만 저장한다. 기존 파일과 실시간 모델, 공식8조합/B6/IRB HOLD/Patch8 실행 보류를 유지하며 commit/push는 하지 않았다.

실행: `python -X utf8 -B compare_new_pilot_lr9.py`; 저장 검증만은 `--verify`(학습 없음).

## 정확도가 내려간 이유와 현재 판단

**이번 자료에서는 9특징이 전체 지표에서 우세하지만, 정상/거북목 문제까지 해결하지는 못했다.**
6특징보다 정상 P0 3건과 상체 전방 P5 4건을 더 맞힌 대신 거북목 P1 2건을 새로 틀렸다.
P1 Recall은60%→50%로 낮아졌다. 따라서 전체 정확도 상승과 모든 자세의 재현율 상승을 같은 의미로 해석할 수 없다.

1. **특징 제거의 이득이 새 자료에서도 유지된다는 근거가 사라졌다.** 기존24구간에서는6특징91.67%,
   9특징87.50%였지만 새113구간에서는 순서가 반대다. 이전의 작은 반복 탐색자료에서 고른6특징을
   보편적으로 더 좋은 조합이라고 확정할 수 없다. 이번은F2·F5·F9를 함께 복원한 비교이므로
   어느 한 특징이 개선/악화를 일으켰는지 분리해서 주장하지 않는다. LR의 나머지 계수도 함께 재학습됐다.
2. **가장 직접적인 증거는 사람을 바꿀 때의 분포·판정 경계 차이다.** 두 모델 모두 학습자료 재대입은
   113/113이지만 LOSO는89/113,94/113이다. 6특징의 P0→P1 오류10건은 모두 F8이 학습 P0의
   관측 범위 밖이고, F8의 음의 점수 기여가 가장 컸다. P1→P0 오류8건도 모두 F7·F8이 학습 P1
   범위 밖이었다. 이는 학습한 한 사람의 범위/경계가 다른 사람에게 그대로 맞지 않는다는 설명을 지지한다.
   관측 범위는 유한 표본 min/max이고 범위를 벗어난 것이 센서 이상이라는 뜻은 아니다.
3. **상체 전방과 거북목의 혼동이 새 자료에서 나타났다.** 기존24구간의 P5 Recall은두 모델 모두100%였지만
   새 자료에서는6특징53.85%,9특징84.62%다. 6특징 P5→P1 6건은 모두 F8의 음의 기여가 가장 크고,
   F1·F4·F6·F7·F8 값이 모두 학습 P5 범위 밖이었다. 얼굴 결측으로 P5 학습구간이3개뿐인 fold에서6건이 발생했다.
   보완 촬영 필요성은 있지만, 표본 부족과 자세 수행/개인차 효과를 이번 관찰로 분리할 수 없다.
4. **단순히 분모가 커져서 정확도가 내려간 것은 아니다.** 정답 비율 자체가 낮아졌으며6특징에서는
   P0 Recall 75%→50%, P1 75%→60%, P5 100%→53.85%로 변했다. P2~P4는100%를 유지했다.
   같은9특징으로 비교해도 이전87.50%→현재83.19%로4.31pp 낮다. 따라서6특징으로 줄인 영향만으로
   전체 하락을 설명할 수 없다. 자료·학습 표본·수행·촬영 세션도 함께 달라졌다.
5. **P0/P1 신호가 전혀 없는 것도 아니다.** F8은 새 자료에서도 두 참가자를 합친 P0/P1 관측 범위가
   분리된다. 그러나 각 fold는 한 사람의 자료로 scaler와6-class 경계를 학습하므로 pooled 범위의 분리가
   실제 LOSO 정답을 보장하지 않는다. 반대로 F3·F4의 P0/P1 내부 범위 겹침은기존1/2명→현재2/2명이다.
   반복 범위와 다중 클래스 계수/절편의 경합이 함께 작용하며 한 가지 특징의 값만으로 오류를 설명할 수 없다.

현재는 **“6특징을 최우선으로 확정”이라는 판단을 유보하고, 9특징을 비교 기준으로 함께 유지**하는 것이 타당하다.
9특징의 현재 전체 성적은 더 좋지만 P1 Recall 50%가 남아 최종 모델로 확정할 근거도 충분하지 않다.
예정된7구간 기술적 보완을 마친 뒤, 사전에 정한 동일 적격 기준과 LOSO/LR 설정으로6·9특징을 다시 비교한다.
틀린 구간을 삭제하거나 그 구간을 맞히기 위해 추가 재촬영·튜닝하지 않는다. 물리적 원인 중 카메라 설치,
의복/ROI, 자세 수행 차이는 현 자료와 미기록 metadata만으로 확정할 수 없다.
