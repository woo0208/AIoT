# 7특징 잠정 고정: SVM-RBF/KNN 오류·실행 비용과 다음 특징 설계

실험 ID: `EXPLR-PILOT120-SEVEN-CANDIDATE-REVIEW-20261108`. F1,F3,F4,F5,F6,F7,F8을 잠정 고정한다. 최신 적격120구간(기존113+P01 P5 보완7), 2인 LOSO 각60/60이며 처음24개는 포함하지 않았다. 반복 탐색자료이고 공식 선정·독립 검증이 아니다.

## 오류 비교

같은7특징의 이전 OOF 지표를 재사용했다. 비용 측정에서 seed0 모델을 다시 학습한 후 모든 시험 예측이 그 결과와 같음을 확인했다. SVM C=1,gamma=1/9,probability=False; KNN k=3,uniform,brute,Euclidean이며 각 train fold에서만 StandardScaler를 fit한다.

|모델|정답/120|Accuracy %|Macro-F1 %|P0 Recall %|P1 Recall %|P2~P5 Recall %|
|---|---:|---:|---:|---:|---:|---:|
|SVM-RBF|114/120|95.00|94.88|100.00|70.00|100.00|
|KNN|113/120|94.17|94.07|95.00|70.00|100.00|

공통 오류는6개로 전부P1→P0다. SVM은총6개, KNN은총7개이며 KNN만P0→P1 1개가 더 있다. 두 모델의 차이는1구간이다.

## 남은 거북목 오류의 직접 근거

SVM의6개 오류와 KNN의 해당6개 오류는같은구간이다. 다른사람의 학습P1 관측 min/max와대조했다.

|특징|학습 P1 범위 밖인 오류/6|학습 P0 중앙값에 더 가까운 오류/6|
|---|---:|---:|
|F1|0|6|
|F3|0|5|
|F4|0|1|
|F5|6|6|
|F6|2|3|
|F7|6|5|
|F8|6|6|

KNN 공통오류의 이웃3개 라벨:

- P0,P0,P0: 2구간
- P0,P0,P1: 1구간
- P0,P1,P0: 3구간

SVM의6-class OVR 점수와 내부P0/P1 OVO kernel 점수를 저장했고, support-vector의 RBF kernel×dual coefficient 합과 절편으로 P0/P1 점수를 정확히 재구성했다. RBF를 선형 계수 기여로 해석하지 않았다. KNN 거리 대조에서도 오류지지항은 F8/F7/F5로 나뉘어 단일 특징만의 문제로 단정할 수 없다.

F5는 얼굴/어깨 투영비, F7/F8은 어깨·흉부ROI·코의 위치 차다. 현재 관측은 참가자 간 기준 이동과 다중 신호 경합을 지지한다. 저장 라벨은 조작자 지정이며 원본 영상을 열지 않았으므로 체형·설치·옷/ROI·실제 자세 수행 중 물리적 주원인을 분리하지 못한다.

## 기존 보조 관측으로 확인한 표현의 한계

CSV에 이미 있는 보조값만 H9 공동지원 안에서 진단 집계했다. 새 특징을 구현하거나 모델에 넣지 않았다. 보조값마다 유효 프레임 수를 기록하고, 기존7특징을 재집계하거나120개 분모를 바꾸지 않았다.

|기존 보조값|관측 가능 구간|공통 오류가 학습P0 중앙값에 더 가까운 수/6|공통 오류가 학습P1 범위 밖인 수/6|
|---|---:|---:|---:|
|exploratory_head_pitch_deg|120|0|1|
|face_matrix_pitch_deg|120|0|6|
|sagittal_torso_lean_deg|120|6|6|
|ear_midpoint_forward_normalized_by_shoulder_width_3d|120|6|6|

기존3D 머리 pitch는6개 오류 모두 학습P1 중앙값 쪽에 더 가까웠고,5/6은학습P1 범위 안이었다. F4와의Pearson r은전체120에서0.905, P0/P1 40개에서0.631다. 7특징 중F3는영상 내 측방축 기울기, F4/F5는머리 회전의2D 투영 신호이며 독립적인3D sagittal 회전 각도는직접 포함하지 않는다. 이관찰은3D 회전 표현 검토의근거지만 완전히새로운정보의누락이나추가성능이득을입증하지는않는다.

## 설계 후보1개: HP3D (설계만, 추가 실험 없음)

새 실험 ID: `EXPLR-PILOT120-HP3D-DESIGN-20261108`. 현재7특징에후속후보1개로검토할HP3D는 기존 engineering `_exploratory_head_pitch_deg`와동일한정의다. 새 수학적 발명으로 포장하지 않고 기존 보조 관측을새 분류 입력으로 제안한다.

```text
E = (LeftEar + RightEar)/2; N = Nose; C = Chin   # D455 XYZ, metres
u = (N_y-E_y, N_z-E_z) / norm((N_y-E_y, N_z-E_z))
v = (C_y-E_y, C_z-E_z) / norm((C_y-E_y, C_z-E_z))
HP3D_t = degrees(atan2(-(u_y+v_y), -(u_z+v_z)))
HP3D_segment = median(valid HP3D_t within the original H9 support)
```

MediaPipe Pose 귀7/8·코0, Face 턱152와 aligned D455 depth를 사용한다. 단위deg, 양수는위로 회전, 음수는아래로 회전이다. 머리 전방 평행이동 자체는상쇄되고 회전이반영된다. 기존 F8은전방 위치이므로 다른물리량이다. 카메라 pitch에는불변이아니며 임상 목각도가 아니다.

후속가설: 깊이위치는정상과비슷하지만 머리회전은P1 쪽인구간에서3D 회전신호를명시하면P1→P0를줄이는가? 단순 C3(몸통 기울기) 또는 EARZ(귀 전방 위치) 추가와다르다. 과거 두방법의실패와 이번두보조위치/몸통값도6개오류를정상쪽에가깝게보는부정적관찰을유지한다. F4와의상관·카메라각·얼굴/귀/턱depth오차 때문에중복되거나정답을악화시킬수있다.

유효조건은필요XYZ와두ray norm>1e-6,합벡터 norm>1e-6, finite angle이다. 후속설계에서는기존7열과120개 identity를고정하고 추가열만원래H9 support와HP3D 유효프레임의교집합에서집계, 유효≥30프레임·원래입력대비coverage≥50%를확인하며결측채움은하지않는다. 현재진단에서최소95프레임, 입력대비최소63.33%로120개모두기술적으로가능했다. 기존CSV에이미값이있어재촬영없이후속검토가가능하다. 해당진단중앙값을이번모델에입력하지는않았다.

기존XYZ가있으면unit ray2개·합·atan2의O(1) 산술과구간집계가추가된다. 7특징운영경로에XYZ가없으면귀/턱depth샘플링과deprojection이추가될수있고결측위험도증가한다. 실제ms/FPS증분은측정하지않았다. 후속모델비교를한다면현재7특징과7+HP3D만고정설정으로비교하는 단일사후가설이며그성능은아직미측정이다.

### 현재 비교 기준과 명칭

- 특징 구성 FS3: F1,F3,F4,F5,F6,F7,F8. 현재 잠정 고정한7특징이며 개별 특징 ID F1~F9와 구별한다.
- 방법 V0: 기존 SVM-RBF. 커널·학습 목적·판정 구조를 개량한 상태가 아니다.
- 학습 설정 T0: C=1, gamma=1/9, class_weight=None 및 기존 생성기의 나머지 설정을 유지한다.
- 기준 표기: `SVM-FS3-V0-T0`. 이는 후속 관리용 표기이며 과거 실험 ID를 소급 교체하지 않는다.
- 개발자료: 최근 적격120구간(기존113+P01 P5 보완7), 2인 LOSO, train-only StandardScaler.
- 기준 관측: Accuracy95.00%, Macro-F1 94.88%, P0 Recall100%, P1 Recall70%, P2~P5 Recall100%.

FS는 특징 구성 변경, V는 방법의 구조 변경, T는 학습 설정 변경을 구분하는 명칭으로 사용한다.
C/gamma/클래스 가중치 조정만으로 새로운 SVM 알고리즘을 제안했다고 표현하지 않는다.
알고리즘 제안형 연구와 RGB-D 응용·오류·비용 분석형 연구 중 논문의 핵심 기여 범위는 아직 구체화할 항목이다.
현재120구간은 특징·모델을 반복 선택한 개발 탐색자료이며 95%를 독립 검증 성능으로 주장하지 않는다.

   클래스별 표본은20개로 균형이므로 클래스 가중치를 검토한다면 표본 불균형 보정이 아닌 오류 비용 가설로 설명한다.
4. T1이 정의된 뒤 동일 FS3/V0/120구간/LOSO/전처리로 T0와 비교하고 실패 결과도 보존한다.
   T1이라는 이름이 채택이나 성능 향상을 뜻하지 않으며 조건을 만족하지 못하면 T0를 유지한다.
5. 실제 방법 개량 V1은 별도의 필요성과 가설이 확인될 때 설계한다.
   HP3D 추가는 별도 특징 분기 FS4 후보로 두고 학습 설정 실험과 섞지 않는다.
6. 개발 후보를 선택한 뒤 특징·설정·전처리·코드를 동결하고, 추후 선택에 사용하지 않은 참가자 자료에서 검증한다.
