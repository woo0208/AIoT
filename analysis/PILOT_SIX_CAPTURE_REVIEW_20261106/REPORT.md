## 특징 결측

완료120구간의 전체 18,000프레임 중 H9 공동 유효는 16,922, 공동 support 밖 프레임은 1,078개다.

P01 P5(상체 전방)에서만2D 특징 F1~F5가 함께 누락됐다. 해당 프레임은 Pose 검출·코·귀 좌표가 유효했지만 양 iris·턱 좌표 flag와 Face matrix가 무효였다. F6~F9 Depth 특징 셀은 존재했다. 따라서 저장 관측상 직접적인 누락 지점은 FaceLandmarker 기반 iris/턱 관측이며, 전체 Pose나 Depth 특징이 함께 사라진 경우는 아니다.

P01 P5 중 부적격7구간의 공동 유효는 0~9/150이었다. 적격 구간은 95/150 1구간, 150/150 2구간이었다. 얼굴 가림·화면 이탈·머리 각도·검출 실패 중 물리적 원인은 CSV만으로 확정할 수 없다.

## 파일·시간·전환 검증

- 완료 실행은 참가자별 정확히1개였다. COMPLETED 상태·동일 identity·완료 수·클래스 균형을 확인해 두 실행을 검토 대상으로 연결했다. 파일명 최신순으로 선택하거나 서로 다른 실행을 이어붙이지 않았다.
- P02에는 별도로 중단된 실행2개(완료2구간·7구간)가 있다. 원본을 보존했고 이번120구간에 합치지 않았다.
- features.csv hash와 실행 당시 capture/probe/geometry/model-lock 코드 hash가 일치했다. 각 완료 구간은 해당 attempt CSV 및 JSON과 행 단위로 정확히 같았다.
- 모든 완료 구간이 기록된10초 반개구간 안에 있으며 device timestamp는 엄격 증가했다. 완료 구간당150프레임이고 PREP/TRANSITION 라벨이나 완료 목록 밖 segment는 main CSV에 없었다.
- 이 검사는 저장 경계와 라벨 기록을 확인한다. 사람이 실제로 자세를 안정적으로 취했는지, 정상 복귀를 정확히 수행했는지를 영상 없이 독립 확인한 것은 아니다.

## 다음 분석의 범위

현재 기존 기준으로 사용할 수 있는 표본은 **113개**이며 P5는 전체13개, 다른 자세는각20개다. P01 P5는3개, P02 P5는10개여서 참가자·자세별 불균형을 반드시 보고해야 한다. 이를120개 모두 적격인 결과로 계산하거나 결측을0으로 채우면 안 된다. 기존24구간과 섞거나 후속 학습을 이번 검토에서 수행하지 않았다.

카메라 높이·의자 거리·설치각·조명은 두 완료 실행 모두 operator metadata가unknown(null)이다. 원본 RGB/Depth 영상은 수집기가 저장하지 않았으며, 카메라 배치·수행 라벨·측정 정확도·독립 sensor frame 누락률은 이번 검토로 확정할 수 없다. 추가 촬영을 자동 실행하거나 기존 누락 구간을 다른 실행으로 대체하지 않았다.

## 보존·검증

review_pilot_six_capture.py는 원본을 읽기만 했다. 이 보고서 외에 참가자별 구간·실행 식별자·누락 flag·타이밍·입력 hash는 local_private/results.json과 DETAILS.md에 저장했다. 원본 입력 bytes 불변, 완료/중단 실행 분리, attempt/main 일치, 시간 경계, 기존 loader 집계·6특징 support 일치와 요약 산술을 확인했다. 모델/카메라/전체 회귀 테스트는 실행하지 않았다. 정식자료 승격·공식8조합/B6/IRB HOLD 변경·commit/push는 하지 않았다.

실행: `python -X utf8 -B review_pilot_six_capture.py`. 저장 검증만: 같은 명령에 `--verify`.

전체120구간의 공동 유효16,922프레임에는 부적격7구간에 남은27프레임도 포함된다. 적격113구간 안의 공동 유효 프레임만 합치면 **16,895개**다. 이 프레임 수를 독립 표본 수로 세지 않는다. 원본·attempt·시간 경계 검증은 PASS지만, 전체120구간이 분석 적격이라는 판정은 아니다.
