# 6특징 LR 오류 진단과 단일 규제 강화 가설

실험 ID: `EXPLR-LR6-REGULARIZATION-20261106`. 기존2인·24구간 반복 탐색 자료다. 일반화·유의성·독립 검증 결과가 아니다.

## 기준 모델과 오류 진단

F1,F3,F4,F6,F7,F8 + 기존 LR C=1. 각 학습12/시험12 LOSO의 seed0 모델을 이전 비용 측정의 로컬 pickle에서 hash 검증 후 복원했다. 기준 모델 재학습은0회다. 24개 OOF 예측은 저장된 LR6 결과와 정확히 같았으며 오류는 P0→P1, P1→P0 각1건이다.

각 fold에서 raw값과 train-only 표준화 z, 학습 실제/오답 클래스 범위, 전6클래스 decision score·확률·순위, 계수·절편을 확인했다. margin=실제 score−최고 다른 클래스 score다. 오류별 기여 `(coef_true−coef_wrong)×z` 합에 절편 차이를 더하면 margin과 일치했다. 상관된 특징의 기준점 의존 대수 분해이며 인과적 중요도는 아니다.

- P0→P1: F7/F8이 가장 큰 음의 기여였다. 시험 P0의 깊이 상대값이 다른 사람의 학습 정상 범위와 달라 P1 쪽으로 점수를 밀었다. 절편은 오히려 P0를 지지했다.
- P1→P0: F4의 음의 항과 절편이 오답을 지지했다. F8은 실제 P1을 지지해 두 오류의 기여 방향이 같지 않았다. F3 등 작은 음의 항도 있었다.
- 두 fold 모두 학습12/12 정답이었다. 다른 사람의 기준값 이동과 작은 학습 표본, 6-class 경계가 관련될 수 있다. 체형·수행·카메라·depth 원인은 이 자료로 분리할 수 없다.

참가자별 raw/z/범위/점수/계수/기여·오류 margin은 local_private/DIAGNOSIS.md 및 baseline_diagnostics.json에만 저장한다. 각 학습 클래스 범위의 표본은2개이며 모집단 범위가 아니다.

## 결과를 보기 전에 고정한 한 가설

**C=1→0.3으로 L2 규제만 강화**해 참가자별 학습 경계에 대한 의존이 줄어드는지 확인한다. 오류가 서로 반대 방향이고 절편 역할도 달라 특정 한 클래스 편향을 바로 추가하지 않았다. 학습이 이미 완전 분류된 작은 자료에서 규제 강화를 검토할 근거는 있으나 성공을 보장하지 않는다.

0.3은 이전8특징 실험의 사전 지정 값에서 재사용한 단일 수준이며 계수/오류를 맞추도록 수치 탐색하지 않았다. 당시8특징 C=0.3은 새 오류를 만들어 실패했다. 그 부정적 결과를 유지하면서 현재6특징의 다른 경계를 별도 확인했다. 클래스 가중치·다른 C·seed·특징·threshold는 시험하지 않았다.

후보 fit 전에 진단을 저장하고 PLAN.json을 배타 생성했다. LR L2/lbfgs/tol=1e-4/max_iter=10000/intercept/class_weight=None/random_state=0은 동일하다. 기준 fold의 train-only scaler를 그대로 재사용하고 실제 학습 행 mean/SD와 대조했다. 새로운 fit은 후보2fold뿐이며 동일24구간·라벨·LOSO·support·집계를 유지했다.

## 검증·보존

실행: `python -X utf8 -B diagnose_six_lr_regularization.py`. 저장 검증만: 같은 명령에 `--verify` (학습 없음).

## 결론

**이번 단일 규제 강화 가설은 개선 근거를 얻지 못했다. 6특징 LR C=1을 유지한다.** 두 기존 오류는 margin이 정답 방향으로 이동했지만 여전히 오답이었고, 기존에 작게 양수였던 다른 정상 구간의 margin이 음수로 바뀌어 P0→P1 오류가 추가됐다. 계수 크기는 줄었으나 예측 성능은 악화됐다. 두 조건 모두 학습12/12 정답이므로 학습 정답률만으로 이 차이를 판단할 수 없다.

정확도는22/24→21/24, P0 정답은3/4→2/4였고 P1 정답3/4 및 P2~P5 Recall은 유지됐다. 이 결과가 다른 C나 클래스 가중치의 모든 가능성을 부정하지는 않지만, 요청한 한 가설 범위를 지켜 추가 설정은 실행하지 않았다. 더 좋은 숫자를 찾을 때까지 반복하지 않았으며 현재 잠정 우선 후보를 교체하지 않는다.
