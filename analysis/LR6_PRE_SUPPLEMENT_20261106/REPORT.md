# 재촬영 전 신규 탐색자료 — 고정6특징 LR 평가

실험 ID: `EXPLR-LR6-PRE-SUPPLEMENT-20261106`. 현재 완료 촬영120구간 중 기존 기준 적격113구간만 사용했다. 기존24구간·P02 중단 실행·후속P5 보완 촬영은 포함하지 않았다. 같은 두 사람의 반복 탐색자료이며 새 참가자 독립 검증이나 정식 평가가 아니다.

## 고정 입력·평가

F1,F3,F4,F6,F7,F8, C=1, L2(l1_ratio=0), lbfgs, tol=1e-4, max_iter=10000, intercept=True, class_weight=None, random_state=0. 기존 fixed_lr 생성기를 그대로 재사용했다. 특징·가중치·규제·라벨·창·seed를 튜닝하지 않았다.

기존 loader의 H9 공동지원 집계(F3 방향성 원형평균, 나머지 중앙값), 유효≥30프레임·coverage≥50%를 유지했다. 저장된 검토의 sample identity·라벨·support·적격성이 재집계와 일치했다. P01 53구간/P02 60구간이며 P5 support는각3/10이다. 첫P0를 제외하거나 개인별 참조를 빼지 않았다. 이번은 기존 파일럿의 무보정 LR 경로다.

참가자 단위 LOSO2fold: 학습60/시험53과 학습53/시험60. 같은 사람의 모든 반복은 한쪽에만 속한다. StandardScaler는 각 학습 fold에서만 fit하고 시험에는 transform만 적용했다. 정확히2회 학습했으며 113개 OOF를 pool해 고정6-class 지표를 산출했다. 참가자별 지표 평균·프레임 분류 정확도·훈련 정확도가 아니다.

환경: NumPy 2.5.3, scikit-learn 1.9.1, native thread=1. 학습 warning을 오류로 처리했으며 수렴 확인을 통과했다.

## 해석의 한계

- P01 P5 7구간은 얼굴 iris/턱 관측 결측으로 제외됐다. 값을 채우거나 기준을 완화하지 않았다. 사용자는 과도한 고개 숙임으로 얼굴이 보이지 않았다고 보고했다. 예측 오류에 따른 제외가 아니며 원본120구간과7개 실패 이력을 보존했다.
- P0~P4는각20개, P5는13개다. P01을 학습하는 fold의 P5는3개뿐이다. 이 불균형은 학습 경계와 P5 평가에 영향을 줄 수 있으므로120개 균형자료의 성능으로 보고하지 않는다.
- Accuracy 한 건은약0.885pp, P0/P1 Recall 한 건은5pp다. 구간 수가 늘어도 독립 참가자는2명이다.
- 기존24구간 결과와는 자료·반복·촬영 조건·제외 분모가 다르다. 표시 점수 차이를 일반화 개선/악화의 확증으로 해석하지 않는다. 카메라 설치 metadata도unknown이다.
- 자세 label은 수집 시 조작자가 지정한 값이며 영상 기반 수행 QA나 임상적 정확성을 검증하지 않았다. 이전 모델 실행 비용은 별도12구간 학습 벤치마크이며 이번113구간에서 재측정하지 않았다.

## 결과 요약

고정6특징 LR은 새 적격113구간에서 **89개 정답·24개 오답**이었다. 오류는 P0→P1 10건, P1→P0 8건, P5→P1 6건이다. P2~P4는 모두 맞혔지만 정상/거북목 혼동과 상체 전방/거북목 혼동이 남았다. 기존24구간의91.67%를 이 새 자료의 성능으로 사용할 수 없다.

P5 보완 촬영은 이번 예측 결과 이전에 결정한 기술적 결측7구간의 보완이다. 이번24개 오분류를 근거로 재촬영 대상을 늘리거나 삭제하지 않는다. 보완 자료의 실제 적격성을 확인한 다음 같은6특징·C=1·참가자 LOSO로 후속 평가해야 하며, P5 보완만으로 P0/P1 성능까지 개선된다고 보장하지 않는다. 이 보고서와 원시 OOF를 재촬영 전 기준 기록으로 보존한다.
