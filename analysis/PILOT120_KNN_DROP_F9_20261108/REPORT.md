# KNN 거리 중복 단일 가설: F9만 제거

실험 ID: `EXPLR-PILOT120-KNN-DROP-F9-20261108`. 같은2명 반복 탐색자료의 사후 가설 실험이다. 공식 선정·독립검증·유의성·일반화 성능 향상으로 주장하지 않는다.

## 사전 근거와 가설

F8=흉부ROI깊이−코깊이(m), F9=F8/3D어깨너비다. 현재120개에서두특징의Pearson r=0.9928, P0/P1 40개에서는r=0.9817다. 기존KNN 남은9개오류의가장가까운정답/다른라벨거리대조에서F9의오답지지항이가장컸다. 이는거리중복검토의근거이며 F9의인과적악영향/제거효과를입증하지않는다.

가설: 표준화거리에서연관된F8/F9의동시반영을줄이려고F9만제외하면P0/P1오류가줄어드는가? 고정KNN9(F1~F9)와KNN8(F1~F8)만비교한다. 여기의8특징은이전6특징에F9를뺀것이아니며 F2/F5는유지한다. 다른열·k·가중치·거리정규화는변경하지않았다.

## 고정 평가

동일120구간/identity/라벨/H9공동지원/적격기준/집계를유지했다. 참가자당60개,자세당20개, LOSO각train60/test60, P01두날짜는같은fold다. StandardScaler는train에서만fit했고기존9특징scaler의첫8열과같았다. 기존factory KNN(k=3,uniform,brute,Minkowski p=2,n_jobs=1)을재사용했다. 기준KNN9는5seed 예측이같아저장된seed0 OOF를재사용했다. KNN은난수인수가없으며 새모델fit은후보2fold뿐이다. 후보fit전에PLAN.json을저장했다. 조합/하이퍼파라미터탐색은없다.

## 해석과 검증

이실험은이미확인한오류에서정한하나의사후가설이다. 현재자료의관측차이를근거로새참가자에서의우세를 보장하거나추가조합을자동탐색하지않는다. 개선이없으면기준KNN9를유지하는판단근거로남긴다.

120개identity/기존입력hash·제거열/고정params·참가자분리/train-only scaler·OOF1회·메모리상직렬화복원·이웃거리/표결·지표/CSV/MD를검증했다. 전체회귀·새촬영·원본영상열람은없다. 코드compare_pilot120_knn_drop_f9.py와이요약을추가하고참가자별OOF/거리/이웃/계획은local_private/에만 저장했다. 기존원본/모델/공식8조합/B6/IRB HOLD/Patch8보류를유지했고Commit/Push는하지않았다.

실행: `python -X utf8 -B compare_pilot120_knn_drop_f9.py`; 저장검증은 `--verify`(학습없음).

## 결과 판단

F9만제외한KNN8은113/120 정답으로 기준KNN9의111/120보다2개 더맞혔다.
Accuracy92.50%→94.17%(+1.67pp),Macro-F1 92.26%→94.07%(+1.81pp)였다.
P1→P0 오류2개를교정했고새오류는없었다. P0 Recall95%를유지하고P1 Recall60%→70%로올랐으며,
P2~P5 Recall은100%였다. 남은오류는P0→P1 1개,P1→P0 6개다.
정상/거북목40개만보면KNN9의31/40(77.50%)에서KNN8의33/40(82.50%)로변했다.

이결과는현재자료에서깊이거리중복을줄이는단일가설을지지하지만, F9가모든상황에서불필요하거나
다른분류기에서도제거해야한다는근거는아니다. 상관과선택된이웃거리대조는인과적특징중요도가아니며,
이번가설은반복탐색자료의기존오류를보고정했으므로2구간개선을독립검증으로해석하지않는다.

현재개발후보는F1~F8+기존KNN(k=3)이다. 이는이전F2/F5/F9를뺀6특징과다르다.
기존9특징KNN을비교기준으로보존하고새특징·추가알고리즘·추가조합탐색은이번에수행하지않았다.
다음에개선가설을더정하려면남은7개오류의거리/특징/수행불확실성을분석해야하며,
현재자료에서최고점이나올때까지열을계속제거하는방식으로이어가지않는다.
