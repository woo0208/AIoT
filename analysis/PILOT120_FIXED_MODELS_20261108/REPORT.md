## 고정 조건과 통합 자료

기존113개 적격 구간+P01 P5 기술적 보완7개=120개, 참가자당60개/자세당20개. 이미 LR 평가에 사용한 동일 행렬·라벨·sample identity를 local_private/dataset120의 samples.csv와 bundle_info.json으로 묶었다. 처음24개·중단 실행·기술적 실패7개는 평가에 합치지 않는다. 원본과 실패 이력은 별도 보존한다. CSV/묶음은 로컬 전용이며 canonical selection manifest가 아니다.

모든 모델 입력은F1~F9. 기존 support/집계/적격 기준을 유지했다. 참가자 LOSO2fold 각60/60이며 P01 두 날짜 세션은 같은 fold다. LR은 저장된9특징 OOF를 재사용해 재학습0회다.

기존 compare_fixed.py의 make_model을 그대로 재사용했다. M0=기존 rf_experiment.Forest, 6-class/500trees/max_features=2/split_w=None, 추가 scaler 없음. SVM-RBF=C=1,gamma=1/9,tol=1e-3,probability=False,나머지 기존 설정 유지; StandardScaler는 train fold에서만 fit. seeds=(0,1,2,3,4)는 과거 탐색 비교와 같고 신규 학습은2모델×5seeds×2fold=20회다. 특징 조합·C/gamma·class weight·임계값을 탐색하지 않았다.

## 현재 자료에서 확인된 개선

SVM-RBF는109/120 정답으로 LR9의103/120보다6개 더 맞혔다. Accuracy는85.83%→90.83%(+5.00pp),
Macro-F1은85.75%→90.34%(+4.59pp)다. 정상 P0 Recall은65%→95%로 올랐고,
LR의P0→P1 오류7개 중6개를 교정했다. 새 오류는없으며 나머지 자세의 예측은LR과 같다.
남은 오류는P0→P1 1개,P1→P0 10개다. 거북목 P1 Recall 50%는개선되지 않았다.

M0는5seeds 평균 Accuracy86.83%,Macro-F1 86.59%,P0 Recall75%,P1 Recall54%다.
P5 Recall이92%로 낮아졌고 P1→P4 오류도 생겨, 모든 자세에서 이득을 얻은 모델은 아니다.
SVM은5seeds 모두 같은 예측이었다. 두 모델 모두 미리 정한 고정 설정만 사용했다.
SVM 학습에서는 기존probability 인수의 API FutureWarning10건을 기록했고 수렴 경고는없었다.
확률 출력/보정을 새로 켜지 않았으며 이 경고 때문에 모델 설정을 바꾸지 않았다.

현재 자료의 관측 개선 후보는9특징 SVM-RBF다. 독립 평가나 최종 운영 모델 선정은아니다.
P1의10개 오류는 다음 개선 가설을 정하기 위한 대상으로 남기고, 이미 실패한 LR 규제/보정을 그대로 반복하지 않는다.
