# P01 P5 7구간 보완 검토와 6·9특징 LR 재평가

실험 ID: `EXPLR-LR6-LR9-POST-SUPPLEMENT-20261108`. 기존 탐색자료의 기술적 결측7구간 보완이다. 정식 평가·독립 검증·최종 모델 선정 결과가 아니다.

## 촬영 품질과 포함 기준

P01 상체 전방(P5) 7구간 완료·7구간 적격. 총1050프레임 중 H9 공동 유효1050개다. 구간별 공동 coverage 100.00~100.00%. 원래 예정한7개 기술적 실패 slot과 일대일 연결했으며 모델 예측을 보고 선택하지 않았다.

기존113구간+보완7구간=120구간. 참가자당60개, 참가자×자세당10개, 각 자세20개다. 원래 실패7개를 학습/평가에 중복 포함하지 않고 원본·사유·연결 이력은 보존한다. 기존24구간·P02 중단 실행은 합치지 않았다. 물리적 CSV 합치기나 원본 덮어쓰기는 없다.

기존 H9 9열 공동지원≥30프레임·coverage≥50%, F3 방향성 원형평균/나머지 중앙값을 유지했다. 6특징=F1,F3,F4,F6,F7,F8; 9특징=F1~F9. 기준 완화·결측 채움·새 특징·튜닝은 없다.

## 해석과 다음 단계

- 보완 후 P5가 균형을 갖췄지만 별도 날짜의 세션이다. 얼굴 관측과 자세 수행이 함께 달라졌을 수 있어 점수 변화를 표본 수 효과로만 설명할 수 없다. 설치 높이·거리·각도·조명은 여전히 미기록이다.
- 참가자는여전히2명이고 같은 사람의 반복 탐색자료다. 보완 촬영은 이전 모델 결과를 이미 본 이후이나 대상7개는 예측 이전에 기술적 결측으로 정했다. 독립 검증/유의성/일반화 성능 향상으로 주장하지 않는다.
- P0/P1의 혼동은 별도 확인해야 한다. 전체 Accuracy만으로 최종 모델을 정하거나 P5 보완이 P0/P1까지 해결했다고 가정하지 않는다. 틀린 구간 삭제·추가 재촬영·가중치/C 탐색을 하지 않았다.
- 필요하면 다음 단계는 기존 고정 RF M0/SVM-RBF를 동일 자료에서 비교하는 것이다. 이번에는 데이터 보완 확인과 LR6/LR9 평가까지만 수행했고 다른 알고리즘·실행 비용은 재측정하지 않았다.

## 결과 판단

보완 후6특징 LR은102/120 정답(85.00%, Macro-F1 84.96%),9특징 LR은103/120 정답
(85.83%, Macro-F1 85.75%)이었다. 두 모델 모두P5 Recall이100%(20/20)다.
기존113개에서6특징의P5→P1 오류6건,9특징의P5→P1 오류2건을 모두 교정했고,
새7개도 모두 맞혔다. 기존 표본에 새로 생긴 오류는 없었다.

P0/P1 예측은 보완 전후 정확히 같았다. 6특징은P0 Recall 50%,P1 60%;
9특징은P0 65%,P1 50%다. 남은 오류는6특징18건,9특징17건이며 모두P0↔P1이다.
이번 보완은 이 탐색자료의P5 혼동을 해결했지만 정상/거북목 구분 개선의 근거는 아니다.

9특징의 전체 정답 이득은1구간(0.83pp)이다. P1에서는6특징이 더 높으므로 전체 정확도만으로
9특징을 최종 선정하지 않는다. 다음 비교는 같은120구간·동일 참가자LOSO에서 기존 고정 RF M0와
SVM-RBF를 적용해 LR의 선형 경계와 다른 분류 경계를 확인하는 방향이다. 다른 모델의 이득은 아직 측정하지 않았다.

총 관측은기존120구간+보완7구간=127구간이며 기술적 실패7개를 제외한120개를 평가했다.
실패 원본을 삭제하지 않았고 보완자료는 별도 날짜에 촬영됐다. 이전113개와 전체120개의 점수 차이에는
학습자료 보충과 평가자료 추가가 함께 포함된다. 이번 결과를 새 참가자/새 세션의 일반화 성능 보장으로 해석하지 않는다.
