# 같은120구간·9특징: 기존5개 분류기 비교 완료

실험 ID: `EXPLR-PILOT120-H9-FIVE-MODELS-20261108`. 추가한 모델은 기존 Linear SVM/KNN뿐이다. LR/RF M0/SVM-RBF는 바로 이전의 동일120구간 결과를 재사용했다. 두 사람 반복 탐색자료이며 독립 검증·최종 운영 모델 선정·새 참가자 일반화 결과가 아니다.

## 입력과 고정 조건

기존113개 적격 구간+P01 P5 보완7개=120개. 참가자당60개, 자세별20개. F1~F9 전부, 동일H9 공동지원/집계/적격 기준/identity/라벨, 동일 참가자LOSO 각60/60을 유지했다. 처음24구간·중단 실행·기술적 실패7개는 포함하지 않았다. P01의 두 날짜 세션은 같은 fold다.

기존 compare_fixed.py의 make_model을 그대로 호출했다. LinearSVC는C=1,L2,squared_hinge, dual=False,OVR,tol=1e-4,max_iter=10000; KNN은k=3,uniform,brute,Minkowski p=2다. 둘 다 각 train fold에서만 StandardScaler fit. seeds=(0,1,2,3,4)를 유지했다. 새 학습은2모델×5seeds×2fold=20회이며 이전3개 모델은재학습0회다. 특징 조합·하이퍼파라미터·임계값·가중치 탐색을 하지 않았다.

## 결과 판단

SVM-RBF가LR9보다 개선됐다는 기존 결과는유지된다. 추가 비교에서는KNN(k=3)이111/120 정답으로
SVM-RBF의109/120보다2개 더 맞혔다. Accuracy90.83%→92.50%(+1.67pp),
Macro-F1 90.34%→92.26%(+1.92pp)다. 기존고정 설정을 바꾸지 않은 결과다.

KNN은SVM-RBF의P1→P0 오류2개를 교정했고 새 오류는없었다. 정상P0 Recall95%는유지하고,
거북목P1 Recall50%→60%로 올랐다. P2~P5 Recall은100%다.
남은 오류는P0→P1 1개,P1→P0 8개다. KNN과Linear SVM 모두5seed에서같은 예측이었고
이번추가 학습에서경고는없었다.

Linear SVM은Accuracy79.17%,Macro-F1 79.41%로 개선되지 않았으며SVM-RBF 대비새 오류14개가 생겼다.
따라서 현재 고정5개 분류기의 탐색 성적은KNN이우세하고, 기존SVM-RBF도유효한 비교 기준이다.
2구간 차이를 새 참가자에서의우월성/일반화 보장으로 해석하거나 최종운영 모델로 자동 확정하지 않는다.
기존5개 알고리즘 비교는여기서 마무리하고, 필요하면KNN의남은9개 오류를 분석해 다음의구체적 가설을 정한다.
다른알고리즘을전부추가하거나k/C/특징조합을자동탐색할근거로 사용하지 않는다.

## KNN이 앞선 이유: 실제 이웃 진단

diagnose_pilot120_knn.py로 저장된 train-only scaler와 원래 학습행을 사용해 거리/표결을 재계산했다. 재학습·새 설정 실험은0회다. 각 시험구간의 표준화9차원 거리 `d²=sum_j((x_j−train_mean_j)/train_sd_j−(neighbor_j−train_mean_j)/train_sd_j)²`를 구하고 가장 가까운3개의 다수결을 복원했다. 120개 예측이 저장된KNN OOF와 정확히 같았으며 3번째/4번째 거리 동점과 표결 동점은없었다. 모든 이웃은시험 참가자와 다른 사람의 학습행이다.

### 현재 자료로 직접 확인한 내용

|대상|구간 수|실제 라벨을 지지한 이웃 수|해석|
|---|---:|---|---|
|P2~P5|80|전부3/3|9차원 가까운 이웃의 자세가 모두 정답이었다|
|SVM 대비 교정|2|전부2/3|경계 부근P1 두 구간에서 이웃 다수결이 맞았다|
|LR 대비 교정|8|전부2/3|P0/P1 경계 구간에서 국소 표결이 맞았다|
|남은 오류|9|전부0/3|가까운 이웃3개가 모두 다른 자세였다|

전체 KNN 정답111/120 중103개는정답 이웃3개,8개는정답 이웃2개였다. 정상/거북목40개만 보면 LR 23/40, SVM 29/40, KNN 31/40이다. KNN의 전체92.50%와 이 두 자세만의77.50%를 구분해야 한다.

SVM 대비교정2개 모두 이웃 라벨이 P1 두 개/P0 한 개였다. 그중한 개는가장 가까운1개가P0였지만 2~3번째가P1이라다수결이P1을선택했다. 이는현재k=3 판정의실제 설명이며 k=1 모델을추가 평가한것은아니다.

LR은클래스별선형점수, SVM-RBF는고정C/gamma로학습한비선형경계, KNN은근처3개표결을사용한다. 이번두P1구간에서는KNN의국소표결이SVM경계보다맞았다. 이를모든비선형경계보다KNN이우수하다는증명이나 SVM하이퍼파라미터가잘못됐다는결론으로해석하지않는다.

### 특징 거리와 실패 원인 단서

각구간에서가장가까운정답라벨행과가장가까운다른라벨행을비교해 `D_j=(z_j−z_other_j)²−(z_j−z_true_j)²`를분해했다. 양수는정답쪽이그특징에서가깝다는뜻이다. SVM대비교정2개에서는F7(어깨 대비 흉부 깊이)의양의항이가장컸고, F9(어깨너비로정규화한코–흉부깊이)의음의항이가장컸다. 따라서정답지지신호와오답지지신호가함께있는구간이었다. 이분해는선택된두이웃사이의거리대조이며 모델전체의특징중요도나인과효과가아니다.

남은9개오류도F9의음의거리대조항이가장컸다. 특히P1오류8개는가까운3개가모두P0, P0오류1개는모두P1이었다. KNN도현재특징에서반대자세와더가깝게보이는구간은해결하지못했다. 이관찰만으로F9를제거해야한다고결정하거나새조합을시험하지않았다.

### 아직 가설인 부분

- 두사람의반복자료에서자세별국소군집이비교적안정적이라거리기반다수결에유리했을가능성이있다. P2~P5의이웃일치와경계8개교정이이를지지하지만새사람/새세션에서의우세는미확인이다.
- 남은P0/P1오류는개인별기준값·수행·카메라/ROI차이가특징공간의위치를옮겼을가능성이있다. F8/F9 등연관된깊이특징이거리에서중복영향을줄가능성도있다. 물리원인과개별특징의제거효과는미확인이다.
- KNN은SVM보다정답2개가많다. 두사람반복탐색에서의작은차이이며독립검증·보편적우월성의증거는아니다.
