# LR F2·F5 동시 제거 — 단일 가설 실험

실험 ID: `EXPLR-LR-DROP-F2-F5-20261106`. 반복 사용한 2인·24구간의 탐색 결과다. 일반화·통계적 유의성·공식 모델 선정 결과로 해석하지 않는다.

가설: F2 제거의 P1 이득을 유지하면서 F5 제거의 P0 이득도 얻을 수 있는가? 네 조건만 비교하며 새 특징·추가 조합 탐색·하이퍼파라미터 튜닝은 하지 않았다.

## 고정 조건

원래 H9 24×9 집계에서 F1~F8 열만 선택했다. 기존 H9 support/집계/라벨/표본 순서와 첫 P0 포함을 유지했다. 참가자당 12구간, 참가자×자세당 2구간, P0~P5 각각 전체 support=4다. 개인 보정·제외·결측 채움·재집계가 없다.

기존 `pilot_data()`/`fixed_lr()`/`score()` 재사용. LR C=1, L2(l1_ratio=0), lbfgs, tol=1e-4, max_iter=10000, intercept=True, class_weight=None, random_state=0. 동일 참가자 LOSO 두 fold(학습12/시험12), StandardScaler는 각 학습 fold에서만 fit한다. 두 fold의 24개 OOF를 pool한 Accuracy·고정6 Macro-F1·Recall이며 참가자별 지표 평균이 아니다.

B0/B0−F2/B0−F5는 이전 검증된 결과를 재사용했다. 입력 hash·identity·라벨·설정·환경·fold·scaler·지표를 다시 확인했고 **새 fit은 F2+F5 제거 2회뿐**이다. 이전 B0의 seed 0~4 예측은 동일했으며 이번도 기존 결정적 seed 0을 유지했다.

환경: NumPy 2.5.3, scikit-learn 1.9.1, native thread 1개.

## 결론

**F2 제거의 P1 Recall 100%를 유지하면서 P0도 개선한다는 가설은 충족하지 못했다.** 동시 제거는 F2 단독 제거 대비 정상 P0→P2 한 건을 교정했지만, 단독 제거로 교정됐던 P1→P0 한 건이 다시 발생했다. 정확도는 22/24로 같고 Macro-F1은 +0.93pp다. 남은 오류는 P0→P1 한 건과 P1→P0 한 건이다.

원래 B0 대비로는 정상 오류 한 건을 교정하고 신규 오류 없이 21/24→22/24가 됐다. 따라서 P0/P1 Recall 75%/75%인 6특징 동시 제거와 50%/100%인 7특징 F2 단독 제거 사이의 선택 문제가 남는다. 이번 결과만으로 한 구성이 모든 면에서 우월하다고 하거나 공식 모델을 교체하지 않는다.

위 저장 검증의 fit 없음은 **LR 재학습 없음**을 뜻한다. 검증에서는 원래 학습 행으로 scaler 통계를 재계산해 저장 mean/scale과 대조하며 시험 행은 사용하지 않는다.
