# SVM-FS3-V0: P1 가중치1.5 단일 T0/T1 비교

실험 ID: `EXPLR-SVM-FS3-V0-T1-P1W15-20261108`. 사용자 지정의 단일 학습 설정 가설이다. 최근 적격120구간의 개발 탐색 결과이며 공식 선정·독립 검증·새 참가자 일반화 결과가 아니다.

## 연구 질문과 사전 고정

7특징 SVM-RBF에서 정상 자세 인식 성능을 크게 희생하지 않으면서 거북목 미탐률을 낮출 수 있는가?

FS3=F1,F3,F4,F5,F6,F7,F8. 방법 V0=SVM-RBF, C=1,gamma=1/9 및 기존 생성기의 모든 나머지 설정을 유지했다. T0는class_weight=None, T1만 `class_weight={0:1.0,1:1.5,2:1.0,3:1.0,4:1.0,5:1.0}`이다. P1은 label_id=1인forward_head다. 평균1로 가중치를 정규화하거나 balanced 모드를 사용하지 않았다. SVM의 sample별 C×class_weight는 P1=1.5, 나머지=1.0이다. 학습 설정 변경이며 알고리즘 구조 개량이 아니다.

같은120개 identity/라벨/H9 집계/적격 기준과 참가자LOSO 각 train60/test60을 유지했다. 참가자별·자세별 학습support는10개, 전체 평가support는각20개다. P01 두 날짜는 같은fold다. 기존24구간·중단 실행·기술적 실패7개는 추가하지 않았다. 기존 train-only StandardScaler를 그대로 재사용했다.

기존 T0 모델2개를 hash 확인 후 복원해120개 예측을 재현했다. T0 fit=0회, T1 fit=2fold의2회뿐이다. seed0을 유지했고 다른가중치/C/gamma/특징/임계값은시험하지 않았다. 후보fit 전에 PLAN.json에설정·입력hash·채택기준을저장했다.

채택기준은 P1 Recall≥80%,P0 Recall≥95%,P2~P5 Recall100% 유지, Accuracy와Macro-F1이저장된T0 원값이상이며 모두충족해야한다. 비교허용오차1e-12는수치반올림용이다. 조건미달이면T0 유지로사전에정했다.
