- 가이드: 「AIoT 앉은 자세 분류 연구 — 팀원용 분석 업무 가이드」(원본 파일명 `AIoT_팀원용_H5_H9_특징기여_및_RF분석_작업가이드_20261029.md`, 작성 기준 2026-10-29).
- 이 문서는 가이드가 **무엇을, 어떤 순서로, 왜** 하라고 했는지를 쉬운 말로 다시 적은 것이다. 가이드 문장을 바꾸거나 새 규칙을 더하지 않았다. 정확한 문장은 가이드 원문을 본다.
- 실제 결과와 숫자는 `summary.md`, 각 업무를 왜 그렇게 했는지는 `work_rationale.md`에 있다.

## 0. 한 문장으로

**"앉은 자세를 맞히는 AI(Random Forest)가 어떤 정보 덕분에 잘 맞히는지, 그리고 가중치를 준 AI는 왜 오히려 못 맞혔는지를, 기존 자료와 고정된 규칙으로 알아보고 근거를 정리해 오라"**는 가이드다.

- **비유:** 요리 대회에서 "이 요리가 맛있는 이유가 소금 때문인지 간장 때문인지" 재료를 하나씩 넣고 빼 보며 알아보는 일이다. 다만 **레시피(코드·설정)는 바꾸지 말고**, **같은 재료(같은 24개 구간)**로, **같은 심사위원(M0)**에게 맛보게 해야 한다.

           → 결과 제출 규칙(§8) → 해석 원칙(§9) → 제출 순서·완료 기준(§10)

## 2. 업무별로 조금 더

### 업무 A — 거리 특징이 얼마나 도움이 됐나 (가이드 §4, 최우선)
- **A-1 더하기:** H5(사진 특징 5개)에 F6, F7, F8, F9를 하나씩 붙여 본다 → 조건 4개.
- **A-2 빼기:** H9(특징 9개)에서 F6, F7, F8, F9를 하나씩 빼 본다 → 조건 4개.
- **A-3 정리:** 조건마다 점수와 **기준선 대비 변화(%p)**, 혼동행렬, P1(거북목) 오류, 참가자별·seed별 결과, 특징끼리의 상관(기존 진단 재사용)을 표로 낸다.
- **주의(가이드):** 하나씩 넣고 뺀 효과를 다 더해도 +15.83%p가 될 필요는 없다(특징끼리 겹치고 영향을 주고받으니까). 하나 뺐을 때 변화가 작다고 그 특징이 쓸모없다고 단정하지 않는다.
- **비유:** 팀 경기에서 선수 한 명을 넣거나 빼 보면서 팀 점수가 어떻게 바뀌는지 본다. 다만 비슷한 역할을 하는 선수가 둘이면, 한 명을 빼도 다른 한 명이 메워서 티가 안 날 수 있다.

### 업무 B — 사진 특징 중 무엇이 중요했나 (가이드 §5)
- H5에서 F1~F5를 하나씩 빼 본다 → 조건 5개.
- **금지:** 값을 0으로 바꾸기, 학습한 뒤에 특징 지우기, 같은 모델 그대로 쓰기. **열을 빼고 처음부터 다시 학습**해야 한다.
- 결론은 **"이 파일럿과 M0에서 빼 봤더니 이렇게 바뀌었다"**까지만 말한다.

### 업무 C — 원 논문 특징과 우리 특징 비교 (가이드 §6)
- 원 논문의 특징 6개를 정의·기준·필요한 입력으로 정리 → 우리 F1~F5와 짝짓기(동일 / 비슷하지만 식이 다름 / 짝 없음).
- 특히 "정상 자세 때 얼굴 면적을 기준으로 한 얼굴 면적 비율" 같은 특징을 지금 자료로 **정확히** 다시 만들 수 있는지 확인한다.
- **다 만들 수 있을 때만** 점수 실험을 따로 제안한다. 못 만들면 **"재현 불가: 빠진 정보/기준"**을 적고, **가짜 점수를 만들지 않는다.**
- 원 논문은 자세 5개, 우리는 6개라서 **"원 논문보다 몇 %p 좋아졌다"고 말하면 안 된다.**

### 업무 D — 가중치를 준 AI가 왜 못했나 (가이드 §7)
- 모델: M0 = 보통 Random Forest, M1 = 입력에 양수 가중치를 곱함, M2 = 특징을 고를 때 가중치를 반영, M3-G = 나중에 만든 다른 방법(M2와 섞지 않음).
- 기존 자료에서 정리할 것 5가지: ① M0와 M1이 똑같이 나온 이유 ② M2에서 어떤 특징·분할이 바뀌었고 P1이 어떻게 틀렸나 ③ 특징 상관·사람마다 다른 분포·P0/P1/P5 혼동 ④ 과적합·표본 부족·가중치 편향은 **가설로만** ⑤ M3-G는 조건이 같을 때만 따로.
- **금지:** 새로 학습하기, λ 바꿔 보기, 좋은 특징 조합 찾기. 근거가 부족하면 "추가 검증 필요"로 남긴다.

## 3. 다 끝났다는 기준 (가이드 §10)

- 기준선을 다시 만들 수 있었는지 설명할 수 있다.
- 업무 A·B는 **다시 돌려도 같은 결과**가 나온다.
- 업무 C·D는 **확인된 사실과 아직 확인 안 된 가설을 나눠** 적었다.
- 기존 실험·실시간 시스템·원자료를 **바꾸지 않았다.**
- 결과를 **팀원 전용 브랜치에서 제출**했다.
