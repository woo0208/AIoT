## 5. P1 검출 (seed 합산, 참가자당 P1 2구간 × 5 seed = 10)

| 참가자 | M0 / M2 P1 행 [P0,P1,P2,P3,P4] | M3-G P1 행 |
|---|---|---|
| P01 | [5, 1, 0, 4, 0] → P1→P0 5/10, P1→P3 4/10 | [0, 0, 0, 10, 0] → 전부 P3(lean_left) |
| P02 | [0, 10, 0, 0, 0] → 전부 정답 | [0, 10, 0, 0, 0] → 전부 정답 |

- P1→P0: M0/M2는 P01의 같은 구간 1개에서 seed마다 발생. M3-G에서는 0건이지만, P01 P1 구간을 P0가 아닌 P3로 보냈기 때문이다. P1 검출이 개선된 것은 아니다.
- P0→P1: M0/M2는 P02의 P0 구간 1개(seed마다). M3-G는 P02의 P0 구간 2개 모두(seed마다).
- P1 Recall은 참가자 사이 차이가 크다: P01 0.1(M0)/0.0(M3-G), P02는 모든 모델 1.0.

## 7. 기존 H9 대비

- 기존 H9 결과(`h6_pilot_20261024_174708.json`)는 **6-class**다. 이번 결과는 5-class이므로 **직접 비교할 수 없다.** 아래 수치는 참고용이다.
  - H9 6-class: M0 Acc 0.783 / F1 0.757 / P1 Recall 0.25 / P1→P5 1.6 per seed. M2 Acc 0.717 / F1 0.670 / P1 Recall 0.05.
- 5-class에서는 P1→P5 오류가 원천적으로 생길 수 없다. 따라서 P1 Recall 0.25→0.55는 class 집합이 달라진 효과와 섞여 있다. **H9→H9-v2 표현 변화의 효과는 이번 실행으로 식별할 수 없다.**
- P1→P5 확인과 6-class 비교는 승인이 없어 수행하지 않았다.
- 알고리즘 축(같은 H9-v2 입력)에서는 M3-G가 M0와 M2 모두보다 낮았다. M2 < M0 경향은 기존 H9 6-class와 같은 방향이다.

## 8. M3-G 저하에 대한 가설 (검증하지 않음)

C3(`sagittal_torso_lean_deg`) 평균값에 참가자 간 기준선 차이가 크다: P0 기준 P01 −15.8°, P02 −4.5°. P01의 P0/P1 C3(약 −15°)는 P02의 P3(−12.0°)에 가깝고, P02의 P0/P1/P3 C3는 모두 P01 P1(−14.9°)보다 큰 쪽에 있다. M3-G는 singleton C3 그룹이 첫 batch 후보에 포함될 확률이 2/3이다. 학습 참가자가 1명(10표본)뿐이므로 C3 분할이 참가자 기준선을 그대로 학습했을 수 있다. 다만 실제 분할 경로는 확인하지 않았다. 이 관찰을 근거로 군 구성이나 상수를 바꾸지 않는다(M3 설계 §7: 파일럿 점수로 군을 고르지 않음).

## 9. 한계

- 참가자 2명, LOSO fold마다 학습 참가자는 1명(10표본)이다. 표본 1개가 pooled 5pp, 참가자 내 10pp에 해당한다. seed 반복은 독립 표본이 아니며, CI나 유의성은 계산하지 않았다.
- 같은 자료로 H9-v2/M3-G를 설계했으므로 재사용 편향이 있다(양방향 모두 가능).
- P01과 P02 사이 카메라 높이·거리·조명 등 촬영 조건은 unknown이다. 참가자 차이와 촬영 조건 차이를 분리할 수 없다.
- 구간 라벨은 operator keypress 기준이다(hold 내부의 전환 동작이 섞일 수 있음).

## 10. 후속 권고

1. 이 결과로 H9-v2 특징, M3-G 군/상수, M2를 수정하지 않는다. M3-G 실패도 허용되는 결과로 기록한다.
2. H9 대비 표현 효과를 보려면 기존 H9로 같은 5-class·같은 표본을 쓰는 M0/M1/M2 비교를 **사전 명세 후** 별도로 실행해야 한다(이번 범위 밖).
3. P1/P5 혼동을 평가하려면 6-class 보조 실험 승인을 Decision Log에 먼저 기록하고, 그 참조로 `--scope auxiliary6`를 실행한다.
4. 평가는 독립 참가자(최소 3~4명 이상으로 outer-training이 여러 명이 되도록)와 formal protocol을 고정한 뒤에 한다(EXP-002, OPEN-005). C3의 참가자 간 기준선 차이는 그 자료에서 기각 가능한 가설로 검증한다.
