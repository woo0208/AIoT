# Published evaluation metrics and aggregates ? 2026-10-29

These are existing two-participant exploratory pilot aggregates, not new experiments or formal validation. No model was trained and no timing or hardware measurement was repeated for this publication.

- [Metric definitions](METRIC_DEFINITIONS.md), [definitions CSV](metric_definitions.csv).
- [Performance](performance.csv), [class metrics](class_metrics.csv), [major error counts](major_errors.csv).
- [Confusion matrices](CONFUSION_MATRICES.md), [mean counts](confusion_matrices.csv), [seed counts](seed_confusion_matrices.csv).
- [Efficiency](efficiency.csv), [measurement status](measurement_status.csv).
- [D455 measurement protocol DRAFT](D455_MEASUREMENT_PROTOCOL_DRAFT.md): unexecuted and unapproved.

The E1/E2 tables describe six-class, 24-segment pilot comparisons. The separate archived H9-v2 primary5 report uses a different five-class scope; their sample counts and metrics must not be combined. Participant codes identify anonymized aggregate scopes, with no identity mapping.

The H9 and LR result histories and their arithmetic-only verifiers remain in [H9 public results](../h9_five_algorithms_20261029/README.md) and [LR public results](../lr_feature_comparison_20261029/README.md). Those packages are not duplicated here.

Individual diagnostic scores, probabilities, feature vectors, source datasets, environment identities and the local unified-results JSON are excluded. References in the archived metric definitions to local diagnostic files describe private evidence, not additional published files. No missing measurement is represented as zero.
