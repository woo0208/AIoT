# 5-D-2 — 평가 규칙 기록과 H9 적격 기준 적용 검토

작성일: 2026-11-02. 채택된 규칙의 authority는 [Decision Log EXP-003](RESEARCH_DECISION_LOG.md#exp-003--5-d-2-정식-6-class-평가보정공통-표본-규칙)이다. 본 문서는 유효 프레임·분모·결측 정의의 제한된 검토이며 새 알고리즘·실행·연구 성능 검증이 아니다.

## 참고와 채택 범위

- [Research Master §24](AIoT_RESEARCH_MASTER.md), [Decision Log](RESEARCH_DECISION_LOG.md): 6-class 주 평가, 개발2/독립검증4, 유지 마지막10초, S1 첫 P0 고정·S2 재사용, 참조 제외·자동 대체 금지·공통 적격 구간·0 대체/자동 보간 금지.
- [Formal Evaluation Plan](../../analysis/formal6_capture_design_20261029_4d9f21/FORMAL_EVALUATION_PLAN.md) §1~7: 기존 DRAFT는 그대로 보존. EXP-003이 열거한 항목만 후속 채택이며 60/120 완전 격자와 synthetic 실행기가 이번 제외 정책을 이미 구현했다는 뜻이 아니다.
- [F0/F_cal 구현 설명](../../F0_FCAL_IMPLEMENTATION.md), `f0_fcal_features.py`: 원시 열별 중앙값 후 특징 계산, None 보존, depth 불필요. 마지막10초 추출·적격 frame count/coverage·학습 제외는 현재 모듈이 구현하지 않는다.
- `f1_sample_aggregator.py`의 `H_MIN_VALID_FRAMES`, `H_MIN_COVERAGE`, `_validate_h_frame_record`, `_aggregate_h_sample`: 현재 H9 구현 사실. 기존 수치를 수정하지 않는다.

## 유효 프레임·분모·결측의 차이

| 항목 | 기존 H9 | 현재 F0 / F_cal |
|---|---|---|
| 프레임 유효 | 9개 특징이 모두 None이 아닌 동일 프레임. 입력 검증에서 숫자/finite를 확인하고 NaN/Inf를 오류로 거부 | F0는 xc/yc/각 θ/A의 정의 가능 여부가 다름. F_cal은 동일 프레임 관측 외에 고정 참조의 해당 baseline이 필요. 숫자 파싱 실패·NaN/Inf는 None으로 정규화 |
| 공통 support | H9 9개 공동 유효 프레임을 H5와도 공유 | 원시 7열의 개별 유효 프레임별 중앙값. 서로 다른 부분집합 가능. 공동 유효 프레임 수 미산출 |
| 최소 수 | 공동 유효 수 >=30 | 현재 기준 없음. 특징별 30인지, 기본 특징 전체 공동 30인지 결정되지 않음 |
| coverage 분모 | 전달된 해당 구간 전체 입력 프레임 수 N. 결측 행도 포함, 중복 frame key는 오류. 예상 FPS×시간이나 센서가 생성한 전체 프레임 수가 아님 | Segment.frames의 행 수는 있으나 coverage·고유 frame key 검증은 없음. 열별 유효 수, 공동 유효 수 중 분자도 미정 |
| 구간 결측 | 공동 support에서 집계. H9 F3 원형 평균이 정의되지 않으면 count/coverage를 통과해도 부적격 | 열별 중앙값을 조합한 뒤 계산. 프레임 각도가 결측이었어도 집계 좌표에서 정의될 수 있고, 반대도 가능. 최종 None 여부만으로 공동 support 30/50 충족을 증명할 수 없음 |
| 보정 참조 | H9 특징 계산에는 참가자 정상 자세 참조 불필요 | F0의 A는 양수 유효 참조 bbox 면적 필요. F_cal은 추가로 각 기본 특징 baseline 필요. 평가 프레임이 충분해도 참조 결측이면 해당 특징 결측 |

현재 F0/F_cal 특징별 결측 의존성:

- xc/yc: 각각 해당 bbox 중심 좌표. 명시적 face_detected=false면 얼굴 관측을 비운다.
- θ2/θ3: 얼굴 중심과 해당 어깨 좌표, 0이 아닌 y 차이. 해당 어깨 valid=false면 그 θ가 결측이다.
- θ1: θ2와 θ3 모두 필요하다.
- A: 양수 현재 bbox 면적과 양수 고정 참조 면적. 얼굴 깊이·oval 면적은 요구하지 않는다.
- F_cal 기본 5개: 해당 현재 기본 특징과 해당 참조 baseline 모두 필요하다. A는 F0와 동일 비율이며 차감하지 않는다.

H9 원형 평균 결측 규칙을 F0의 arctan 합/차감에 그대로 적용할 수 없고, F0에 H9의 depth 의존성을 추가할 근거도 없다.

## 적용 가능 / 추가 결정 필요

**적용 가능한 구조:** 마지막10초의 사전 고정 구간을 비교 대상에 동일하게 사용하고, 결측 행을 유효 프레임으로 세지 않으며 유효 수·전체 입력 수·최종 특징 결측을 따로 기록할 수 있다. 30개 이상과 50% 이상이라는 숫자는 F0/F_cal에서도 기술적으로 검사 가능하다. 다만 동일 숫자가 동일 관측 품질을 의미하지 않으며 이번 작업은 그 채택/구현 승인이 아니다.

**추가 연구 결정 필요:**

1. F0/F_cal 프레임 유효를 6개 특징 공동 유효로 정의할지, 원시 입력 공동 support 또는 특징별 support로 정의할지. 기존 열별 집계를 공동 support 집계로 바꾸면 계산 결과가 달라질 수 있으므로 자동 변경하지 않는다.
2. coverage 분모를 마지막10초에 실제 전달된 고유 전체 프레임(결측 관측 행 포함)로 둘지, 누락된 수집/처리 프레임까지 어떻게 반영할지. 15FPS×10초=150으로 자동 대체하지 않는다. 시간축·창 경계·짧은 구간 처리도 사전 고정해야 한다.
3. 30개·50%를 F0/F_cal의 목표 구간과 보정 참조 구간 각각에 적용할지, 참조 면적과 5개 baseline에 동일 요건을 요구할지. 현재 코드에는 보정 성공을 포괄하는 적격 플래그가 없다.
4. 부분 보정 실패를 특징별 부적격으로 둘지 참가자 전체 부적격으로 둘지, 공통 비교 집합에서 어떤 표본을 제외할지. 다른 P0 대체·0 대체·자동 보간 금지는 이미 확정이며 유지한다.
5. 특징군 공통 비교는 동일 구간의 적격 교집합으로 확정됐지만, 구간 내 H9/F0/F_cal까지 동일 원시 프레임 교집합을 강제할지는 미확정이다. 프레임 교집합을 강제하면 기존 집계 support가 달라질 수 있다.

이 항목들이 결정되기 전에는 H9의 30/50을 F0/F_cal 정식 eligibility로 적용 완료했다고 보고하지 않는다. 결측 후 남은 표본 수·클래스 support·제외 이유는 실제 자료가 있을 때 보고하며, 수치 목표에 맞춰 역치·참조·창을 바꾸지 않는다.
