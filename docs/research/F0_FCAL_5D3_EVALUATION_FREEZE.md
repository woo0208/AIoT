# 5-D-3 — F0/F_cal 평가 support·coverage·보정 규칙 동결

**Status:** CONFIRMED / DESIGN-FROZEN (아래 승인 범위만)
**Logged:** 2026-11-02
**Authority:** 연구자의 이번 명시적 승인; Decision Log `EXP-004`.
**Scope:** 5-D-2에서 미확정으로 분리했던 F0/F_cal의 분석 창, 공동 support, coverage, 목표/참조 적격성 및 부분 보정 실패 처리. 구현 완료·실제 검증 결과·실행 승인을 뜻하지 않는다.

## 승인된 규칙

1. **공동 support:** 동일 프레임에서 얼굴 bbox, 양쪽 어깨 및 F0 계산에 필요한 관측값이 모두 유효한 프레임만 사용한다. 기존 F0 계산의 입력·결측 의미를 유지한다. 얼굴 중심과 양 어깨 좌표, 양수 bbox 면적이 필요하며 기존 각도 식이 정의되지 않는 관측을 유효로 세지 않는다. 열마다 다른 프레임을 골라 공동 유효 프레임으로 간주하지 않는다. 깊이·oval·H9 특징의 유효성을 새 요건으로 추가하지 않는다.
2. **집계 순서:** 위 동일 공동 support에서 각 원시 입력의 중앙값을 구한 뒤 기존 F0/F_cal 특징을 계산한다. 프레임 특징을 먼저 계산해 그 중앙값을 쓰는 방식으로 바꾸지 않는다. 특징 수식·좌우·단위·A 비율은 기존 계산 모듈의 정의를 유지한다. 기존 모듈의 열별 독립 support 경로가 이 규칙을 이미 구현했다는 뜻은 아니다.
3. **coverage:** `N`은 마지막 10초 분석 창의 실제 입력 프레임 수, `J`는 그중 공동 유효 프레임 수이며 coverage=`J/N`이다. 관측 결측/무효 프레임도 실제 입력이면 N에 포함한다. 수집·처리 중 아예 누락된 프레임을 가상 입력으로 보충하지 않고, 프레임 누락률은 별도로 기록한다. nominal FPS×10초를 N으로 대체하지 않는다. 입력이 없으면 coverage는 정의되지 않으며 유효 수 요건도 충족하지 못한다.
4. **목표·참조 적격성:** 각 목표 구간과 참가자의 첫 P0 보정 참조 구간 모두 `J >= 30` 및 `coverage >= 0.50`을 만족해야 한다. 보정 참조는 추가로 집계 참조 면적이 양수이고 기준 특징 5개가 모두 유효해야 한다. 원시 공동 관측 요건과 최종 집계 특징의 정의 가능 여부는 별도 확인 사항이며, 결측 최종 특징을 모델 입력으로 넘기지 않는다.
5. **보정 실패:** 참조의 위 요건이 하나라도 실패하거나 기준 특징이 부분 결측이면 해당 참가자의 F0/F_cal 평가를 불가 처리한다. 후속 P0나 S2 P0, 평가 구간, 예측 결과, 다른 참가자의 정보로 자동 대체하지 않는다. 이 실패로 H5/H9 자체 평가의 적격성을 변경하지 않는다. 다만 F0/F_cal을 포함한 직접 공통 비교에서는 해당 참가자의 표본이 공통 적격 교집합에 들어갈 수 없다. H5/H9 자체 평가와 공통 비교의 분모를 구분해 보고한다.
6. **시간 범위:** 자세 유지 종료 시각을 `T_end`라 할 때 목표 및 참조 분석 창은 `[T_end - 10초, T_end)`로 고정한다. 왼쪽 경계 포함, 종료 시각 제외이며 전환 구간은 제외한다. 전환/준비 프레임을 보충하거나 창을 앞으로 이동해 수를 맞추지 않는다.
7. **기존 고정 규칙 유지:** 참가자별 S1 첫 P0 고정, S2 동일 참조 재사용, 참조 P0의 F0/F_cal 학습·평가 및 특징군 공통 비교 표본 제외, 동일 참가자·구간의 공통 적격 표본 비교, 0 대체·자동 보간 금지를 유지한다. 이번 사용자 지시의 5-D-1 규칙은 저장소에서 `EXP-003` / Master §24에 기록된 동일 규칙과 연결한다. 별도의 과거 5-D-1 승인 문서가 존재한다고 소급 주장하지 않는다.

## 적용 범위와 기존 결정의 관계

- [5-D-2 검토서](F0_FCAL_5D2_EVALUATION_RULES.md)의 미확정 1번(공동 support·집계), 2번 중 coverage 분모와 시간 경계, 3번(목표/참조 threshold), 4번(부분 보정 실패)은 이번 범위에서 확정됐다. 당시 미확정 기록은 보존한다.
- 그 검토서 5번의 **서로 다른 특징군까지 동일 원시 프레임 교집합을 강제할지**는 이번 승인에 포함되지 않았다. F0/F_cal 내부의 공동 support와 특징군 간 공통 적격 구간 집합은 구별한다. H5/H9 계산·support를 변경하지 않는다.
- `OPEN-005`는 위 항목에 한해 부분 해결이다. 실제 불완전 자료의 클래스/탈락·재촬영·선택·ok_with_warnings·formal seed/metric 등 전체 protocol은 여전히 미완료다. `OPEN-005` 전체 RESOLVED로 표시하지 않는다.
- `OPEN-002` / `OPEN-003`의 F1/F2 전체 정의를 확정하지 않는다. `OPEN-001`, `OPEN-004`, `OPEN-006`의 기존 해소 상태와 frozen Patch 4~8 계약은 변경하지 않는다.
- 개발2/독립검증4 및 6-class 주 평가 규칙을 유지한다. 기존 Formal Evaluation Plan과 기존 합성 실행기의 보정 전 완전 격자 분모는 보존 기록이며, 새 제외/실패 정책의 실제 분석 분모로 재사용하지 않는다.

## 아직 남은 연구·운영 결정

- 특징군 간 프레임 교집합 강제 여부. 공통 **구간** 비교는 이미 확정됐다.
- 짧은 유지 구간·시간 메타데이터 부족, 목표 실패·불완전 클래스·탈락 및 재촬영/selection의 후속 처리. 마지막 10초 창과 30/50 기준을 사후 완화하는 승인은 아니다.
- 프레임 누락률 기록에 사용할 장치/처리 단계, 기대 프레임 수·분모·근거와 시간축/종료 마커의 실제 데이터 연결. coverage 분모나 반개구간 경계 자체는 더 이상 미확정이 아니다.
- 기존 F0 구현 설명에 남은 원문 재현의 불명확성 전체, 정식 모델/scaler·seed·metric freeze와 윤리/접근/실행 조건. 이번 승인 범위를 넘어 일괄 해소하지 않는다.

EXP-002 및 CAP-007 EXECUTION DEFERRED를 유지한다. 이번 작업은 문서 동결만이며 코드 수정·실행기 연결·학습·테스트·실제 촬영·commit/push를 수행하지 않는다.
